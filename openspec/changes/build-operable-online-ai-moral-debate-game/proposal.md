## Why

《活该》的核心乐趣需要尽快通过可公网部署的双人实时网页 MVP 验证。当前优先验证房间对战、道德辩论、AI 裁决和哲学审判，不建设管理、账号或商业化基础设施。

## What Changes

- 建设通过房间码邀请的在线双人实时对战，支持服务端权威计时、断线重连和房主自定义比赛时限。
- 实现每局三回合的人物出牌、词条附加、单轮攻防、AI 列车长裁决、最终审判与哲学评议。
- 使用项目内置且经过审查的中文人物、默认卡面、词条和列车长人格牌库；玩家不能上传或编辑内容。
- 由 Node.js 服务端调用 OpenAI 兼容 API，并提供失败降级，密钥不进入浏览器。
- 使用原创黑白粗线、夸张表情、网点拼贴的荒诞漫画视觉，不复制参考作品的具体角色、素材、字体或商标。
- 提供单体 Docker 化部署、桌面浏览器验收和自动化测试计划。

## Capabilities

### New Capabilities

- `realtime-match`: 房间创建与加入、规则配置、服务端权威状态机、倒计时、掉线重连和比赛结算。
- `moral-debate-gameplay`: 固定发牌、人物出牌、词条附加、单轮攻防、论据沉淀、三回合单局和多局比赛。
- `ai-adjudication`: 服务端 OpenAI 兼容调用、结构化裁决、最终审判、哲学评议和确定性降级。
- `builtin-content`: 内置人物、默认卡面、词条与列车长人格牌库及启动校验。
- `player-session`: 无账号昵称身份、房间席位和断线重连令牌。
- `web-experience`: 完整玩家端流程、原创荒诞漫画视觉、桌面端可用性和网络状态反馈。

### Modified Capabilities

无，当前仓库尚无既有 OpenSpec 能力规格。

## Impact

- 预计新增 React + TypeScript + Vite 玩家端、Node.js + Fastify + Socket.IO 单体服务和共享类型。
- 使用 SQLite 保存短期房间/比赛快照，活跃房间主要由单进程内存状态管理；不引入管理端、Redis、PostgreSQL 或对象存储。
- 需要定义 REST/Socket.IO 契约、游戏状态机、AI 结构化输出和 Docker 部署方式。
- 对局结束数据默认保留 24 小时后清理；内置牌库随应用版本发布。
